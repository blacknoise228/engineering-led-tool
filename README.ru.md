## 💡 О приложении

**Engineering LED Tool** — это специализированное настольное приложение для инженеров видеосопровождения, технических специалистов, VJ-ев и прокатных компаний. 

Программа изначально была разработана для личного пользования, упрощения подготовки LED экранов к мероприятию или инсталляции:
- Проектирование геометрии экранов из модулей любых размеров и шага пикселя.
- Отрисовка наглядных схем расключения кабинетов витой парой с направлением сигнала и порядковыми номерами модулей в цепи.
- Автоматический контроль лимита пикселей на порт контроллеров NovaStar и других похожих по ограничениям.
- Моментальный расчет общей спецификации: количество кабелей, портов, карт, оптических конвертеров CVT, общей площади ($м^2$) и потребляемой электрической мощности (кВт, А).
- Создание точных пиксельных растровых масок для серверов (Resolume Arena, disguise, TouchDesigner, Watchout, Millumin) с возможностью интеграции вашего фирменного логотипа.
- Двуязычный интерфейс (русский и английский языки) с автоопределением языка операционной системы.

## ⚡ Ключевые возможности

- 📐 **Интерактивный холст:** свободное масштабирование, панорамирование, привязка (snapping) по краям, центрам и углам.
- 🔌 **Трассировка сигнала:** ручное соединение кабелями или интеллектуальное автоподключение «змейкой» выбранных кабинетов с выбором шага и направления.
- 🎛️ **Экосистема NovaStar:** поддержка передающих карт и видеопроцессоров NovaStar и похожих по ограничениям количества пикселей на порт.
- 🖥️ **Медиасерверы:** возможность добавлять свои медиасерверы для отображения в спецификации.
- 🎨 **Брендированные маски:** экспорт пиксельных масок экранов для подготовки контента с кастомным логотипом компании, настройкой размера и смещения.
- 📋 **Спецификация в один клик:** генерация подробного текстового райдера оборудования для отправки в чаты техникам, менеджерам или заказчику.
- 💾 **Формат `.ss` с интеграцией в Windows:** сохранение проектов в компактный файл с возможностью открытия в программе двойным кликом из проводника.
- 🖼️ **Экспорт высокого разрешения:** сохранение схем в PNG и ZIP-архив.
- 🌐 **Двуязычный интерфейс:** полная поддержка русского и английского языков с автоматическим определением языка системы и быстрым переключением в приложении.

## 📸 Скриншоты и возможности

### 1. Схема расключения по сигналу (Wiring)

Схема наглядно отображает цепочки коммутации сигнальными патч-кордами между кабинетами:
- Каждая передающая карта или видеопроцессор подсвечивается уникальным цветом.
- На каждом кабинете отображается его порядковый номер в сигнальной линии порта.
- Ведется подсчет занятых пикселей на порт в 8-бит:
  - **24 Hz:** до 1 649 306 px / порт
  - **25 Hz:** до 1 583 333 px / порт
  - **30 Hz:** до 1 319 444 px / порт
  - **50 Hz:** до 791 667 px / порт
  - **60 Hz:** до 659 722 px / порт
- Доступна функция автоматической коммутации выделенных кабинетов цепочкой в одно нажатие.

### 2. Генерация pixelmap масок и брендинг с кастомным логотипом

Вкладка **«Маски» (Mask)** позволяет настроить координаты экранов относительно холста:
- Объединение модулей в именованные группы экранов (например: *Left Banner*, *Center Stage*, *Right Column*).
- Разрешения холста подстраивается под расположенные на нём экраны.
- **Кастомный логотип компании:** возможность загрузить логотип вашей продакшн- или прокатной компании, который будет выводиться на бейджах экранов.
- Настройки логотипа:
  - Загрузка изображения (PNG / SVG).
  - Масштаб (Scale) и отступы (X/Y Offset).
- Экспорт готовых масок в высоком разрешении пиксель в пиксель.

### 3. Пресеты карт и видеопроцессоров NovaStar

Вкладка **«Карты» (Cards)** и окно пресетов позволяют добавлять карты которыми вы пользуетесь:
- Добавление и переименование контроллеров.
- Указание типа устройства: передающая карта (Sending card) или видеопроцессор (Processor).
- Настройка максимального количества физических Ethernet портов.
- Добавление в списки оптоволоконных трансиверов NovaStar CVT (CVT10, CVT4K-S).
- Импорт и экспорт базы пресетов карт в формате JSON (`cards.json`).

### 4. Пресеты LED кабинетов (панелей)

Программа позволяет создавать пресеты кабинетов:
- **Параметры пресета:**
  - Название модели (например, *Dicolor-C 500×1000 4.8mm*).
  - Физические габариты: ширина и высота в миллиметрах (мм).
  - Разрешение: ширина и высота в пикселях (px).
  - Шаг пикселя (Pixel Pitch, мм).
  - Энергопотребление одного кабинета (Вт).
  - Вес кабинета (кг).
  - Флаг специальной формы (Special panel) для лэд сетки с черезстрочным пропуском пикселей.
- Управление базой: добавление, дублирование, удаление, экспорт и импорт пресетов в файл `panels.json`.

### 6. Сводная спецификация оборудования и расчет нагрузки

Вкладка **«Инфо» (Info)** мгновенно генерирует полный технический отчет:
- Название события и дата проведения.
- **Общая сводка:**
  - Количество физических экранов и общее количество панелей (шт.).
  - Общая площадь светодиодного полотна в квадратных метрах ($м^2$).
  - Общий вес экранов / полотна (кг).
  - Количество межпанельных перемычек (RJ45 patch cords).
  - Суммарное количество задействованных портов контроллеров.
- **Экраны:** расчет количества панелей, веса и энергопотребления для каждого экрана в отдельности.
- **Детализация по моделям кабинетов:** точное количество модулей каждого типа.
- **Список контроллеров/карт:** список задействованных карт и добавленных оптоволоконных блоков CVT.
- **Расчет электропитания (Сила):**
  - Суммарная потребляемая мощность в кВт и Вт.
  - Расчет силы тока при 3-фазном подключении 230 В (в Амперах на фазу).
- **Используемые медиасерверы:** назначенный сервер или пул машин.
- Кнопка **«Скопировать спецификацию»** для быстрой вставки готового текста в мессенджер, техрайдер или смету.

## 📁 Файлы проектов `.ss`

Engineering LED Tool сохраняет всю структуру проекта в файлах с собственным расширением **`.ss`**:
- В файле сохраняются все страницы расключения, страницы масок, привязанные контроллеры, трассировка коммутации, пресеты и метаданные события.
- Установщик регистрирует ассоциацию расширения `.ss` в Windows — проект открывается двойным кликом мыши.
- Реализована поддержка перетаскивания (Drag & Drop) и одиночного экземпляра программы (открытие второго файла не запускает лишний процесс, а передает проект в уже открытое окно).
- Проекты также совместимы с форматом `.json`.

## 🛠️ Пошаговое руководство (Быстрый старт)

1. **Создание и расстановка панелей:**
   - Перейдите во вкладку **«Панели»** на боковой панели.
   - Выберите пресет кабинета и настройте размеры сетки ($Cols \times Rows$ панелей).
   - Нажмите **«Добавить сетку»** или кликните по холсту для свободного размещения.
2. **Позиционирование:**
   - Перетаскивайте панели мышью. Они автоматически примагничиваются по граням и центрам.
   - Используйте выделение рамкой для одновременного перемещения групп кабинетов.
3. **Назначение контроллеров:**
   - Во вкладке **«Карты»** добавьте требуемый процессор (например, *NovaStar VX1000*).
   - Выберите активную карту и порт Ethernet.
4. **Расключение:**
   - Включите инструмент коммутации или воспользуйтесь автоподключением «змейкой».
   - Соедините кабинеты в нужной последовательности.
5. **Создание маски:**
   - Переключитесь во вкладку **«Маски»**.
   - Нажмите **«Добавить экран из расключения»**, чтобы импортировать контуры экрана.
6. **Выгрузка результатов:**
   - Во вкладке **«Инфо»** скопируйте сформированную спецификацию оборудования.
   - Нажмите `Ctrl + E` для сохранения схемы в PNG или экспортируйте маски в ZIP.

## 💻 Сборка из исходников

Если вы хотите собрать приложение самостоятельно из исходного кода:

### Требования
- [Go 1.21+](https://go.dev/)
- [Node.js 18+](https://nodejs.org/)
- [Wails CLI v2](https://wails.io/docs/gettingstarted/installation)

### Инструкция

```bash
# 1. Клонирование репозитория
git clone https://github.com/blacknoise228/engineering-led-tool.git
cd engineering-led-tool

# 2. Установка зависимостей фронтенда
cd frontend
npm install
cd ..

# 3. Запуск приложения в режиме live development
wails dev

# 4. Сборка финального бинарника и инсталлятора под Windows
wails build -platform windows/amd64 -nsis
```

Собранный инсталлятор и портативный `.exe` появятся в папке `build/bin/`.
